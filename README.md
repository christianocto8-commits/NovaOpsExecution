# NovaOps Enterprise

NovaOps Enterprise is a multi-outlet operations execution platform for task management, outlet execution, reporting, drafts, workflow visibility, and operational quality control.

## Stack

- Frontend: Next.js, React, TypeScript
- Backend: FastAPI
- Database: PostgreSQL
- Migration: Alembic
- Runtime: Docker Compose
- CLI: `novaops.ps1`
- CI: GitHub Actions

## Developer Onboarding

```powershell
git clone <repository-url>
cd NovaOpsExecution
.\bootstrap.ps1
.\novaops.ps1 doctor
.\novaops.ps1 dev
```
