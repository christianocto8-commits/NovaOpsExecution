# NovaOps UI Design System

NovaOps uses a clean enterprise UI system inspired by modern operational platforms.

## Current Components

- Button
- Card
- Badge
- PageHeader
- PageContainer
- EmptyState
- StatCard
- SectionHeader
- SearchInput

## Design Language

- Minimal enterprise interface
- Slate neutral base
- Emerald accent for operational status
- Large rounded cards
- Clear hierarchy
- Dashboard-first layout
- Reusable components for future modules
