# NovaOps Enterprise Architecture Overview

NovaOps is an enterprise multi-outlet operations platform designed for operational execution, task management, checklist compliance, issue escalation, audit workflows, and performance visibility.

## Core Stack

- Backend: FastAPI
- Database: PostgreSQL
- ORM: SQLAlchemy
- Migration: Alembic
- Frontend: Next.js 16
- Language: TypeScript
- Styling: Tailwind CSS
- Data Fetching: TanStack Query
- Authentication: JWT

## Core Principles

- Multi-organization by default
- Multi-outlet by default
- Feature-first frontend structure
- Shared reusable UI components
- Backend modular domain structure
- Enterprise-ready permission model
- Scalable task and workflow foundation
